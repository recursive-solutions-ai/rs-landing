> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a dedicated `/lucy` deep-dive page (Granola-inspired, warm chrome + a contained dark interactive product showcase), wire it as the destination of the Offerings "Lucy" card, and consolidate the homepage's full "system" section into a slim teaser that links to it.

Spec: [docs/superpowers/specs/2026-06-29-lucy-page-design.md](../specs/2026-06-29-lucy-page-design.md).

- **`bun run lint` is BROKEN project-wide** (Next 16 removed `next lint`; no eslint config) — this is pre-existing and out of scope. Do NOT run `bun run lint`. Wherever a task step says "typecheck + lint", satisfy it with `bunx tsc --noEmit` (plus `bun run build` where the step also lists build). This global note supersedes every per-task `bun run lint` reference.
- **Dev server runs on `:3001`** (the Brain app holds `:3000`). The CONTROLLER starts/owns the dev server for visual checks; implementer subagents do static verification (`bunx tsc --noEmit`, `bun run build`) only and need not drive a browser.
- **No component-test runner exists.** Do NOT add jest/vitest-dom/testing-library. Presentational components are verified by **typecheck + build + the controller running the app** (dev server + Playwright), per the project's testing guidance ("skip framework boilerplate and trivial wrappers"). - **Theme tokens only:** use DaisyUI semantic classes (`base-100/200/300`, `base-content`, `primary`, `neutral`, `neutral-content`). The only literal colors allowed are the animation's teal accent (`#00d3bb`, light `#7fffe9`) and they appear ONLY on the dark `neutral` showcase band.

- **Copy rules (from spec §8):** "Lucy" = the platform (capital L). Sub-agents are "experts" (Nancy/Sam/Fran/Otto), never "bots". Stages are numbered `02–05`.
- **Locale:** routes live under `[locale]`; `params` is a `Promise` in Next 16 — `const { locale } = await params`. Internal links that start with `/` must be locale-prefixed (`/${locale}/lucy`). Hash links (`#contact`) need no locale.

```ts
// src/components/lucy/stages.ts
export interface LucyStage {
	/** Tab label shown to the user. */
	label: string
	/** Two-digit marker matching the LucyAnimation scene markers (02–05). */
	marker: string
	/** One-line caption shown under the showcase for this stage. */
	caption: string
}

export const LUCY_STAGES: LucyStage[] = [
	{ label: 'Content Engine', marker: '02', caption: 'One brand voice, fanned out to blog, social, and SEO — automatically.' },
	{ label: 'Lead Capture', marker: '03', caption: 'Forms feed your inbox; an auto-reply fires in seconds.' },
	{ label: 'Pipeline', marker: '04', caption: 'Every lead moves new → contacted → qualified → won, tracked end to end.' },
	{ label: 'Custom Experts', marker: '05', caption: 'Lucy hands work to named experts trained on your business.' },
]

/** Clamp an arbitrary index into the valid stage range [0, LUCY_STAGES.length - 1]. */
export function clampStageIndex(index: number): number {
	if (Number.isNaN(index)) return 0
	return Math.max(0, Math.min(index, LUCY_STAGES.length - 1))
}
```

- [ ] **Step 1: Write the component**

```tsx
// src/components/lucy/LucyShowcase.tsx
"use client"

import { useState, type KeyboardEvent } from "react"
import { LucyAnimation } from "@/components/landing/LucyAnimation"
import { LUCY_STAGES, clampStageIndex } from "./stages"
import { useReducedMotion } from "@/hooks/useReducedMotion"
import { useInView } from "@/hooks/useInView"
import { cn } from "@/lib/utils"

export function LucyShowcase() {
	const [active, setActive] = useState(0)
	const reduce = useReducedMotion()
	const { ref, inView } = useInView<HTMLDivElement>()

	function onKeyDown(e: KeyboardEvent<HTMLDivElement>) {
		if (e.key === "ArrowRight") {
			e.preventDefault()
			setActive((i) => clampStageIndex(i + 1))
		} else if (e.key === "ArrowLeft") {
			e.preventDefault()
			setActive((i) => clampStageIndex(i - 1))
		}
	}

	return (
		<section className="bg-neutral text-neutral-content">
			<div
				ref={ref}
				className={cn("mx-auto max-w-5xl px-6 py-24", inView && "reveal-in")}
			>
				<p className="reveal mb-3 text-center text-xs font-extrabold uppercase tracking-[0.2em] text-neutral-content/50">
					A look inside Lucy
				</p>
				<h2 className="reveal font-display mb-10 text-center text-3xl font-semibold md:text-4xl">
					See Lucy work.
				</h2>

				{/* Tabs */}
				<div
					role="tablist"
					aria-label="Lucy stages"
					onKeyDown={onKeyDown}
					className="reveal mb-6 flex flex-wrap justify-center gap-2"
				>
					{LUCY_STAGES.map((stage, i) => (
						<button
							key={stage.marker}
							role="tab"
							id={`lucy-tab-${i}`}
							aria-selected={active === i}
							aria-controls="lucy-tabpanel"
							tabIndex={active === i ? 0 : -1}
							onClick={() => setActive(i)}
							className={cn(
								"rounded-full border px-4 py-2 text-sm font-semibold transition-colors",
								active === i
									? "border-[#00d3bb] bg-[#00d3bb]/15 text-[#7fffe9]"
									: "border-white/15 text-neutral-content/60 hover:text-neutral-content"
							)}
						>
							<span className="font-mono text-xs opacity-60">{stage.marker}</span>{" "}
							{stage.label}
						</button>
					))}
				</div>

				{/* Device frame */}
				<div
					id="lucy-tabpanel"
					role="tabpanel"
					aria-labelledby={`lucy-tab-${active}`}
					className="reveal overflow-hidden rounded-2xl border border-white/10 bg-black/40 shadow-2xl"
				>
					<div className="flex items-center gap-1.5 border-b border-white/10 bg-white/5 px-4 py-3">
						<span className="h-2.5 w-2.5 rounded-full bg-white/20" />
						<span className="h-2.5 w-2.5 rounded-full bg-white/20" />
						<span className="h-2.5 w-2.5 rounded-full bg-white/20" />
					</div>
					<LucyAnimation mode="tabbed" active={active} reduce={reduce} />
				</div>

				<p
					className="reveal mt-5 text-center text-sm text-neutral-content/70"
					aria-live="polite"
				>
					{LUCY_STAGES[active].caption}
				</p>
			</div>
		</section>
	)
}
```
